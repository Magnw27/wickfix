Documentation

Developer reference

The endpoints behind WickAI — documented and runnable. Expand an endpoint to edit its request, press Run to call the live server, or copy a ready-made curl snippet.

Try it yourself

Each endpoint includes a working request. Click one to expand it, edit the JSON if you like, then run it against the live instance to see the response.

Error handling

HTTP errors

Non-2xx responses return a JSON body shaped as {"error": "…"} with the matching status code. Failures are shown with a clear red badge instead of silent breakage.

Stream errors

During streaming, the server emits a data: {"error": true, "message": "…"} event. The app keeps whatever was already generated and shows the error inline.

No API key

If OPENROUTER_API_KEY is not configured on the server, chat and image endpoints return 500 with a friendly message.
